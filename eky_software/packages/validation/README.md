# Validation package

Tämä paketti sisältää syötteiden validointiin liittyvät skeemat ja apurakenteet.

Vastuut:

- tarkistaa käyttäjän tai API:n syötteen muoto
- tarjota jaettavia validointiskeemoja
- tukea frontend- ja backend-validointia

Validointi ei korvaa domain-sääntöjä.

Skeleton-vaiheessa tähän pakettiin ei lisätä vielä Zodia tai muuta validointikirjastoa.
