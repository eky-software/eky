# Domain package

Tämä paketti sisältää Eky-järjestelmän puhtaan liiketoimintalogiikan.

Sallittua:

- domain-tyypit
- arvotyypit
- tilat
- tilasiirtymät
- laskentafunktiot
- liiketoimintasäännöt

Kiellettyä:

- React
- Firebase
- Zod skeleton-vaiheessa
- tietokantakirjastot
- HTTP-kutsut
- selain-API:t
- backend frameworkit

Domain on järjestelmän sisin kerros eikä saa riippua ulkoisista teknologioista.
