# Config package

Tämä paketti sisältää yhteisiä konfiguraatiotyyppejä ja ympäristöasetusten lukemisen periaatteita.

Vastuut:

- ympäristöjen nimet
- konfiguraatiotyyppien määrittely
- turvallinen asetusten lukemisen malli

Salaisuuksia ei koskaan sijoiteta frontendin julkiseen konfiguraatioon.

Skeleton-vaiheessa tähän pakettiin ei lisätä vielä varsinaista ympäristöasetusten lukijaa.
