# UI package

Tämä paketti sisältää myöhemmin uudelleenkäytettäviä käyttöliittymäkomponentteja.

Sallittuja komponenttityyppejä myöhemmin:

- `Button`
- `Input`
- `Select`
- `Textarea`
- `Card`
- `Modal`
- `Table`
- `FormField`
- `PageHeader`
- `EmptyState`

Kiellettyä:

- liiketoimintalogiikka
- API-kutsut
- Firebase-kutsut
- tietokantakutsut
- laskutuslogiikka
- moduulien sisäiset säännöt

Skeleton-vaiheessa tähän pakettiin ei lisätä vielä React-riippuvuutta.
